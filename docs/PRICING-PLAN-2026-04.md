# SiteVibe 料金プラン設計書

作成日: 2026-04-02
ステータス: 承認済み（実装前）

## 背景

SiteVibe の提供コンセプトを見直し、料金体系を再設計した。

### コンセプトの変遷
- **旧**: 「AIがあなたのサイト上で、自動で接客する時代へ。」（Web接客+Chatta標準搭載）
- **新**: 「話しかけるだけでサイトが変わる、機能が増える」（AI管理画面「Vibe」中心）

### 変更の理由
1. AI編集（Vibe）がサービスの主軸に変わった
2. Chattaは全顧客が必要とは限らない → オプション化で原価管理しやすくする
3. ブログ機能も独立オプションとし、使わない顧客にコストを押し付けない
4. Premiumの「更新し放題」は原価リスクがある → 上限設定

## オプション: Chatta（AIチャットボット）

Chattaは独立したSaaS（chatta-bot.com）だが、SiteVibe顧客にはオプション価格で提供する。

### 技術仕様
- デフォルトLLM: Claude Haiku 4.5（コスト効率重視）
- Pro版: Claude Sonnet 4.6 選択可
- RAG: pgvector + OpenAI Embedding (text-embedding-3-small)
- 埋め込み: Shadow DOM ウィジェット（script タグ1行）
- バックエンド: Supabase + Vercel

### SiteVibeオプション価格

| | Chatta Light | Chatta Pro |
|---|---|---|
| **月額（税込）** | +¥3,300 | +¥8,800 |
| 月間対話数 | 300件 | 2,000件 |
| FAQ登録数 | 30件 | 無制限 |
| URL自動取込 | 月1回 | 月10回 |
| エスカレーション | メール | メール+LINE |
| ブランディング除去 | なし | あり |
| LLMモデル | Haiku 4.5 | Sonnet 4.6（選択可） |

### 原価・粗利（Haiku 4.5ベース）

| | Chatta Light | Chatta Pro |
|---|---|---|
| API原価 | ~¥450 | ~¥3,000 |
| 粗利率 | 86% | 66% |

※ Chatta Pro で Sonnet 4.6 使用時: 原価 ~¥9,000、粗利率 -2%（要注意）
→ 現状は対話数が少ないため問題なし。対話数が増加した場合はHaiku切替を検討。

- `blog_pro` — ¥5,500/月

**従量課金:**

- `blog_plan`: ブログオプション（null/blog_light/blog_pro）

※ chatta_plan, blog_plan カラムはPhase B実装時に追加
